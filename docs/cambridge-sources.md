# Cambridge curriculum source register

Updated: 17 October 2026

## Editorial policy

Cambridge Path uses publicly accessible Cambridge English handbooks, exam formats,
wordlists, sample papers and activity indexes as alignment references. All lesson
prompts, answer choices and explanations in the application are newly authored.
Commercial books are listed as recommended references and are never copied into
the application.

catalogue. Official commercial families referenced in the in-app library include
Fun Skills, Storyfun, Complete, Compact, Trainer, Exam Booster, Objective
Proficiency, Grammar in Use and Authentic Practice Tests; availability is linked
to the [Cambridge English shop](https://shop.cambridge.org/english/home).

## Coverage implemented

- Six CEFR levels from A1 through C2.
- Twenty-four original lessons across vocabulary, grammar, reading, listening,
  writing and speaking.
- Data-driven questions, answer feedback and source attribution.
- Level-specific exam blueprints and Cambridge English Scale ranges.
- A filterable in-app library separating free official resources from commercial
  reference books.

## Known boundary

This source register is comprehensive for the qualification path implemented by
the application, not a mirror of Cambridge University Press's entire catalogue.
The store contains many unrelated general-English, business, academic and teacher
training products that are outside this product's A1–C2 exam-preparation scope.
